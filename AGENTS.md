# Owned-fork agent policy

AI-assisted coding, instrumentation, experiments, tests, and research are allowed in this `teamleaderleo/FEX` fork.

This fork is an experimental research surface. Code created here must not be represented as an upstream FEX contribution merely because it exists in this fork.

Any future contribution to FEX upstream must be independently derived and prepared in accordance with the upstream repository's current contribution policy at the time of submission.
